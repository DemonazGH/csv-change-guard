A focused comparison, with clear limits.

The beta checks a documented subset of Shopify product CSV fields. It is useful only when that subset fits your workflow.

A good fit when you have

  • UTF-8, comma-delimited product CSV files from the same store and currency.
  • Recognized handle, Title, and SKU columns, with stable, non-empty SKUs.
  • Exact, case-sensitive handle + SKU pairs that can identify the variants you want to compare.
  • Up to 5,000 data records and 10 MiB per file, with at most 200 columns.
  • A need to review prices, selected product/option/visibility fields, explicit clears, and comparison gaps.

Outside this beta’s coverage

  • Images, inventory, shipping, taxes, market-specific prices, and metafields.
  • Arbitrary supplier formats, XLSX, semicolon-delimited files, and every Shopify schema dependency.
  • Fuzzy matching, guessed identifiers, or matching variants whose handle or SKU has changed.
  • Store connections, imports, automatic corrections, backups, or import simulation.
  • A guarantee that Shopify will accept an import or that an import is safe.
Zero findings does not mean “approved to import.” Missing or ambiguous identifiers make comparison incomplete. An absent row is not a deletion prediction. Omitted columns are unassessed; they are different from explicit blank cells.
Price format and browser evidence

Prices must be non-negative dot-decimal values with up to 12 integer digits and 6 decimal places. No currency symbols, locale guessing, negative prices, or scientific notation. Threshold arithmetic is exact within that supported range; displayed percentages are truncated to two decimal places.

Automated Windows checks on 21 October 2026 passed in installed Chrome 155.0.8059.85 and Edge 155.0.4283.62, using both standalone-file and localhost navigation with browser sandboxing enabled. This is evidence for those tested versions and routes, not a guarantee for all browsers, managed devices, or merchant workflows.

Before you decide

Practical questions

Do my CSV files leave my computer?

The utility reads selected files and creates reports in your browser. It does not upload CSV contents, connect to Shopify, send telemetry, or persist your catalog in local storage. Downloaded reports can contain catalog values, so store and share them with care. A future payment provider would separately process purchase details; it does not need your catalog files.

Do I need a Shopify app installation or an account here?

No store installation, Shopify credentials, product account, or API key is required to run the utility. The proposed purchase would be handled separately by a payment provider. This independent utility is not affiliated with or endorsed by Shopify.

Can I send you a file to compare for me?

This beta is a self-service utility. Support should start with error text and synthetic reproductions, not catalog attachments or store credentials. A two-business-day email response target is proposed. The actual support address must be supplied before a paid release.

What happens if my browser blocks downloaded HTML?

Extract the package before opening the app. Some managed browsers restrict local HTML. An optional localhost fallback using Node.js is included for users who can run it; it is not a backend or upload service. If your device policy prevents both routes, check with your administrator rather than disabling browser sandboxing.

Is the beta a complete Shopify import validator?

No. It compares supported fields using the tool’s exact handle + non-empty SKU key. That key is not a claim about Shopify’s importer identity rules. Review the report’s coverage, assumptions, and limitations, keep an appropriate backup, and validate your actual import workflow separately.
