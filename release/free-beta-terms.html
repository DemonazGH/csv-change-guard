4. Coverage and local processing

The utility is a read-only comparison aid for a supported subset of two Shopify product CSVs from the same store and currency. It uses exact, case-sensitive handle plus non-empty SKU matching. This is the tool's comparison key, not Shopify's importer identity rule. Missing or ambiguous identifiers make comparison incomplete.

Each file must be UTF-8, comma-delimited CSV with recognised handle, Title and SKU columns, within 5,000 data records, 10 MiB and 200 columns. Omitted columns, explicit blank cells and absent rows are different states. An absent row is not a deletion prediction.
