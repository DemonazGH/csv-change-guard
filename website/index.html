Know what is assessed

Useful findings.
Explicit boundaries.

The utility compares a documented subset of Shopify product CSV fields. It uses exact, case-sensitive handle + non-empty SKU pairs; it does not guess matches from row order.

  • Price changes and a configurable movement threshold
  • Explicitly cleared supported fields
  • Supported option and visibility changes
  • Missing, duplicate and unmatched identifiers

Absent rows are not predicted deletions. Omitted columns are not treated as explicit blanks. Zero findings is not approval to import.

UTF-8, comma-delimited CSV

Both files need recognized handle, title and SKU columns. Use non-empty SKUs, supported dot-decimal prices, and files from the same store and currency.

Images, inventory, taxes, shipping, market-specific prices, metafields and arbitrary supplier formats are outside comparison coverage.

Your catalog stays with you

No store connection. No CSV uploads.

The downloadable utility reads selected files in your browser and processes them locally. The public demo runs the same comparison engine with fixed synthetic inputs only. Neither uploads catalog files, calls AI services, tracks usage or asks for Shopify credentials.

This website has no file upload or contact form. Cloudflare handles technical request data; consumer Gmail handles support and trial correspondence. Read our website and support privacy notice. Please use synthetic examples and do not send merchant CSVs, reports, passwords or payment details.

This is an independent comparison tool, not a complete Shopify import simulator. Review coverage, keep an appropriate backup and test your actual import workflow separately.
