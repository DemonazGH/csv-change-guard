## Behavior and scope

Visitors can run a fixed fictional catalog/update pair without signup, read all
15 findings, filter six priority findings, request a complete HTML report
download and reset the results. The static report and two synthetic CSVs are
also directly linked. The engine and demo assets are copied byte for byte from
`src/engine.js` and `src/demo.js`; the hosted interface is separate from the app.

There is no file picker, pasted CSV, URL-supplied input, store connection,
upload, payment, persistence or telemetry. Only first-party static scripts load.
The demo CSP preserves `connect-src 'none'` and `form-action 'none'`. The homepage
and privacy page still disallow scripts. Hosting receives ordinary technical
requests; this is not a claim that no provider records exist. Account/privacy/
analytics settings were not changed.

Trial instructions describe recent Shopify CSV experience, Windows Chrome/Edge,
English instructions, an unpaid voluntary synthetic exercise of up to 45 minutes,
and the existing support email. Package access is arranged individually after
fit is confirmed. No package was emailed or published. The privacy notice adds
trial-enquiry handling under the existing support purposes/retention procedure;
no marketing consent, recruitment database or mailing list was introduced.
